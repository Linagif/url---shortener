# URL Shortener

A simple URL shortener built with Python, Flask, and SQLite.

## Status
In development.

## Planned features
- Shorten a long URL
- Redirect from a short code to the original URL
- URL validation
- Simple web interface

## Tech stack
Python, Flask, SQLite

## Run locally
```bash
python -m venv venv
venv\Scripts\activate      # Mac/Linux: source venv/bin/activate
pip install -r requirements.txt
python app.py
```
Then open http://127.0.0.1:5000
